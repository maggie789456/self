## 一、上传到 GitHub 并发布成网页（约 3 分钟）

### 1. 新建仓库
登录 GitHub → 右上角 **+** → **New repository** → 填写仓库名（如 `topsale`）→ 可见性选 **Public**（免费账号的 Private 仓库不能开 Pages）→ **Create repository**。

### 2. 上传文件
进入新仓库 → **Add file** → **Upload files** → 把本目录下的文件（`index.html`、`README.md`）**平铺拖进上传区**（不要放进子文件夹）→ 下方点 **Commit changes**。

### 3. 开启 Pages
仓库 → **Settings** → 左侧 **Pages** → **Source** 选 `Deploy from a branch` → **Branch** 选 `main` + `/ (root)` → **Save**。

等待 1～2 分钟，访问地址即：

```
https://<你的GitHub用户名>.github.io/<仓库名>/
```

这个链接就可以直接发给商家了。

> 补充：若希望完全跳过 GitHub Pages 的 Jekyll 处理，可在仓库根目录用 **Add file → Create new file** 新建一个空文件，命名为 `.nojekyll` 后提交。本页面是纯静态单文件，不加也可正常访问。

## 二、页面用法

| 区域 | 说明 |
|---|---|
| 顶部导航 | 🔥 大爆品潜力商品 ｜ 🧣 夹克外套 两个板块 |
| 左侧导航 | 随顶部板块联动：看「大爆品潜力商品」时列出推荐类目；看夹克外套时列出区域（欧区 / 全球 / 美区） |
| 推荐类目分组 | 超大号类目标题 + 高亮的「📂 类目路径」条 + 绿色「📋 复制类目路径」大按钮 |
| 商品卡片 | 首图（点击放大查看原图）+「跳转商品页」+「复制类目路径」两个按钮 |
| 数量统计 | 顶部板块数字、左侧导航计数、区域小计、类目分组小计 |

- **复制类目路径**：点击后按钮变蓝显示「✅ 已复制」，粘贴出来就是上面两条完整推荐路径。
- **跳转商品页**：新窗口打开对应商品页面。
- **图片放大**：点击首图弹出大图，支持 `←` `→` 切换、`Esc` 关闭，弹窗内同样有「跳转商品页」按钮。
- 手机 / 平板打开时左侧导航会自动收起，用顶部板块导航即可。

## 三、使用提示

1. 建议使用 Chrome / Edge / Safari 等现代浏览器打开；微信内置浏览器也可正常浏览。
2. 图片为在线加载，**打开页面和放大看原图都需要联网**，且需能访问图片域名。
3. 若个别商品没有首图链接，卡片会显示「暂无首图」占位，跳转按钮仍可正常使用。
4. 页面采用懒加载，滚动到可视区域才加载图片，避免一次性占用过多并发请求。
