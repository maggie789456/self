# 男装爆款机会商品集合页

给商家参考的款式机会集合页，按 **衬衫 / 亨利衫 / 夹克外套 / 皮衣** 四大类目分区展示商品图片，支持**一键复制类目路径**与**点击跳转商品页**。

- 单文件网页：`index.html`（数据内嵌，无需后台、无需构建）
- 图片为**在线加载**（直接引用数据表中的首图链接），仓库中不含图片文件，体积很小
- 已针对 GitHub Pages 部署做过适配，可直接作为静态网页发布给商家访问

---

## 一、上传到 GitHub 并发布成网页（约 3 分钟）

### 1. 新建仓库
登录 GitHub → 右上角 **+** → **New repository** → 填写仓库名（如 `topsale`）→ 可见性选 **Public**（免费账号的 Private 仓库不能开 Pages）→ **Create repository**。

### 2. 上传文件
进入新仓库 → **Add file** → **Upload files** → 把本目录下的 3 个文件（`index.html`、`README.md`、`.nojekyll`）**平铺拖进上传区**（不要放进子文件夹）→ 下方点 **Commit changes**。

> `.nojekyll` 是一个空文件，用于跳过 GitHub Pages 的 Jekyll 处理，保证页面原样输出。如果上传时看不到它，请先把系统/资源管理器设置为“显示隐藏文件”（Mac 按 `Cmd + Shift + .`）。

### 3. 开启 Pages
仓库 → **Settings** → 左侧 **Pages** → **Source** 选 `Deploy from a branch` → **Branch** 选 `main` + `/ (root)` → **Save**。

等待 1～2 分钟，访问地址即：

```
https://<你的GitHub用户名>.github.io/<仓库名>/
```

这个链接就可以直接发给商家了。

## 二、页面用法

| 区域 | 说明 |
|---|---|
| 顶部导航 | 🔥 大爆品潜力商品 ｜ 👔 衬衫 ｜ 🧥 亨利衫 ｜ 🧣 夹克外套 ｜ 🥼 皮衣 五个大板块 |
| 左侧导航 | 随顶部板块联动：看「大爆品潜力商品」时列出四大类目；看某类目时列出该类的区域（欧区 / 全球 / 美区 / 未标注） |
| 叶子类目分组 | 超大号类目标题 + 高亮的「📂 类目路径」条 + 绿色「📋 复制类目路径」大按钮 |
| 商品卡片 | 首图（点击放大查看原图）+「跳转商品页」+「复制类目路径」两个按钮 |
| 数量统计 | 顶部板块数字、左侧导航计数、区域小计、叶子类目分组小计 |

- **复制类目路径**：点击后按钮变蓝显示「✅ 已复制」，可直接粘贴使用。
- **跳转商品页**：新窗口打开对应商品页面。
- **图片放大**：点击首图弹出大图，支持 `←` `→` 切换、`Esc` 关闭，弹窗内同样有「跳转商品页」按钮。
- 手机 / 平板打开时左侧导航会自动收起，用顶部板块导航即可。

---

## 三、使用提示

1. 建议使用 Chrome / Edge / Safari 等现代浏览器打开；微信内置浏览器也可正常浏览。
2. 图片为在线加载，**打开页面和放大看原图都需要联网**，且需能访问图片域名。
3. 若个别商品没有首图链接，卡片会显示「暂无首图」占位，跳转按钮仍可正常使用。
4. 请勿在页面中占用过多并发请求：页面采用懒加载，滚动到可视区域才加载图片。
